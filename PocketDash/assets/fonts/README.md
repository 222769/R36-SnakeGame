# Fonts

`DejaVuSans-Bold.ttf` is the game's UI font (DejaVu fonts licence, see
`DejaVu-LICENSE.txt`, free to redistribute). At startup it is rendered into
one anti-aliased glyph atlas per text size.

To use a different face, replace the file, keeping the name. If the file is
missing, the game falls back to its built-in 5x7 pixel font.
