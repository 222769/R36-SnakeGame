# Levels

World 1 (Sunny Meadows) lives here as plain-text `.lvl` files:

| File  | Level           | Objective / idea                                    |
|-------|-----------------|-----------------------------------------------------|
| 1-1   | Welcome Meadow  | Tutorial: move, hop thorns, dash crates, stomp      |
| 1-2   | River Run       | Rafts, a bridge and streams to hop                  |
| 1-3   | Coin Forest     | Collect 40 coins in a forest maze (magnet helps)    |
| 1-4   | Lost Friends    | Rescue 3 chicks with Y; one is behind a locked gate |
| 1-5   | Dash Valley     | Crate walls, wide thorns (hop + dash), Super Dash   |
| 1-6   | Hidden Garden   | Find all 3 stars: secret hedge, key, tiny gap, giant |
| 1-7   | Star Sprint     | Timed: reach the flag in 75 seconds                 |
| 1-8   | Meadow Guardian | Boss arena (the boss arrives in Phase 7)            |

The files are generated by `tools/make_world1.py`. Edit the generator,
not the `.lvl` files, then run `python3 tools/make_world1.py`. It refuses
to write a level where anything is unreachable. The format and map legend
are documented in `src/LevelLoader.h` and `src/Level.h`.

You can hand-edit a level too: `pocketdash --check-levels` reports any
problem with a line number, and `pocketdash --play --level 1-3` jumps
straight into a level.
